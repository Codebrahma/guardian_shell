Policy Editor

Edit file access, exec, and network policies per agent. Changes are saved to the config file on disk.

File Access Policy

Controls which files the agent can read/write. Deny rules always override allow rules.

Pattern syntax:
/tmp/**          # Everything under /tmp/
/etc/hosts       # Exact file match
/home/user/*.log # Single-level wildcard
Example allow list (default: deny):
/tmp/**
/proc/**
/usr/lib/**
/home/user/project/**
Example deny list:
/etc/shadow
/home/user/.ssh/**
/home/user/.aws/**
/home/user/.gnupg/**
Symlink bypass warning

If a parent folder is in allow and a subfolder is in deny, an agent can bypass the deny by creating a symlink from an allowed path (like /tmp/) to the denied folder. eBPF sees the raw path, not the resolved target.

Mitigation: Don't allow broad parent directories that contain denied subfolders. Instead, allow only the specific subdirectories you need. For cgroup agents, Landlock provides inode-level protection but only for allow rules (not deny).

Safe pattern for denying subfolders:
# WRONG (symlink bypass possible):
allow = ["/home/user/**"]
deny  = ["/home/user/secret/**"]

# RIGHT (allow only what's needed):
allow = [
  "/home/user/projects/app1/**",
  "/home/user/projects/app2/**",
  "/home/user/.config/**",
]
# secret/ is not in allow list — blocked by default

Exec Policy

Controls which commands the agent can execute. Uses the same pattern syntax as file access.

Important: Binaries may exist at multiple paths!

On merged-usr systems (Fedora, Arch), /bin, /sbin, /usr/bin, /usr/sbin may all contain the same binary. When denying a command, list ALL known paths. Use which -a <cmd> to find them.

# Example: deny grep at ALL known paths
/usr/bin/grep
/bin/grep
/usr/sbin/grep
Allowlist approach (default: deny):
# Only allow specific tools
/usr/bin/git
/usr/bin/node
/usr/bin/python3
/bin/bash
Blocklist approach (default: allow):
# Block dangerous commands
/usr/bin/curl
/usr/bin/wget
/usr/bin/rm
/usr/bin/ssh
/usr/bin/scp
Tip:

With default: deny, allow the agent's own binary, a shell, and all needed tools.

Network Policy

Controls outbound TCP connections by port number. Enforced by eBPF LSM socket_connect hook + Landlock (kernel 6.7+).

Common ports:
80    # HTTP
443   # HTTPS
22    # SSH
5432  # PostgreSQL
3306  # MySQL
6379  # Redis
8080  # Dev server
Example (default: deny, allow specific):
Allow: 80, 443
# Agent can only make HTTP/HTTPS requests
Example (default: allow, block specific):
Deny: 22, 25, 3306, 5432
# Block SSH, SMTP, database ports
