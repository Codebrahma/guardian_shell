OpenClaw Agent Integration

Launch Procedure

Important: OpenClaw uses jiti (JIT TypeScript) for plugins. You must build outside the cgroup first, then launch inside it.

Step 1 — Build TypeScript (run outside cgroup):

pnpm openclaw --dev gateway

Step 2 — Wait for startup, then Ctrl+C

Step 3 — Launch inside cgroup sandbox:

sudo guardian-launch --name openclaw --memory 2G --pids 150 -- pnpm openclaw --dev gateway

Adding the Permission Tool to OpenClaw

Step 1 — Create the tool file at openclaw/src/agents/tools/guardian-permission-tool.ts:

Click to expand full source code 
import { Type } from "@sinclair/typebox";
import { execSync } from "node:child_process";
import { type AnyAgentTool, jsonResult, readStringParam } from "./common.js";

const GuardianPermissionSchema = Type.Object({
  resource_type: Type.String({
    description: '"file" for file access or "exec" for command execution',
  }),
  resource_path: Type.String({
    description: "Absolute path to the file or executable",
  }),
  justification: Type.Optional(
    Type.String({ description: "Why this access is needed" }),
  ),
});

export function createGuardianPermissionTool(opts?: {
  agentName?: string;
  guardianCtlPath?: string;
  socketPath?: string;
}): AnyAgentTool {
  const agentName = opts?.agentName ?? "openclaw";
  const ctlPath = opts?.guardianCtlPath
    ?? "/home/suren/codebrahma/guardian_shell/target/release/guardian-ctl";
  const socketPath = opts?.socketPath ?? "/run/guardian.sock";

  return {
    label: "Guardian Permission",
    name: "guardian_request_permission",
    displaySummary: "Request temporary access from Guardian Shell operator",
    description:
      "Request temporary permission for a blocked file or command. " +
      "Blocks until human approves/denies (up to 120s). " +
      "Use on EACCES errors. Always provide a justification.",
    parameters: GuardianPermissionSchema,
    execute: async (_toolCallId, args) => {
      const params = args as Record<string, unknown>;
      const resourceType = readStringParam(params, "resource_type", { required: true });
      const resourcePath = readStringParam(params, "resource_path", { required: true });
      const justification = readStringParam(params, "justification");

      if (resourceType !== "file" && resourceType !== "exec")
        return jsonResult({ approved: false, error: 'must be "file" or "exec"' });
      if (!resourcePath.startsWith("/"))
        return jsonResult({ approved: false, error: "must be absolute path" });

      // --socket goes BEFORE the subcommand (top-level flag)
      const cmd = [
        ctlPath, "--socket", socketPath,
        "request-permission",
        "--name", agentName,
        "--path", resourcePath,
        "--resource-type", resourceType,
      ];
      if (justification) cmd.push("--justification", JSON.stringify(justification));

      try {
        const stdout = execSync(cmd.join(" "), { timeout: 180_000, encoding: "utf-8" });
        const m = stdout.match(/APPROVED:\s*(.+?)\s*\(granted for (\d+)s\)/);
        if (m) return jsonResult({ approved: true, reason: m[1],
          grant_duration_secs: parseInt(m[2], 10),
          message: `APPROVED for ${resourcePath}. Retry now (${m[2]}s grant).` });
        return jsonResult({ approved: true, reason: stdout.trim() });
      } catch (err: unknown) {
        const e = err as { stderr?: Buffer|string; stdout?: Buffer|string };
        const se = e.stderr?.toString() ?? "", so = e.stdout?.toString() ?? "";
        if (/AUTO[_-]DENIED/i.test(so))
          return jsonResult({ approved: false, message: "Auto-denied (never-approve list)" });
        if (se.includes("timed out") || so.includes("timed out"))
          return jsonResult({ approved: false, message: "Timed out (120s)" });
        if (se.includes("rate limit") || so.includes("rate limit"))
          return jsonResult({ approved: false, message: "Rate limited" });
        const dm = so.match(/DENIED:\s*(.+)/);
        if (dm) return jsonResult({ approved: false, message: `Denied: ${dm[1]}` });
        return jsonResult({ approved: false, message: se || so || "Unknown error" });
      }
    },
  };
}

Step 2 — Register in openclaw/src/agents/openclaw-tools.ts:

// Add import at top:
import { createGuardianPermissionTool } from "./tools/guardian-permission-tool.js";

// Add to tools array (before the closing ]);
    ...(pdfTool ? [pdfTool] : []),
    createGuardianPermissionTool(),   // <-- add this
  ];

Step 3 — Add guardian-ctl to agent's exec allow list in config.toml:

[agents.exec_policy]
allow = [
    # ... existing entries ...
    "/path/to/guardian-ctl",  # add this
]

Step 4 — Enable interactive permissions in config.toml:

[agents.permissions]
interactive = true
max_grant_duration_secs = 300
max_grant_total_secs = 1800

Permission Request Flow

OpenClaw has a guardian_request_permission tool. When it gets "Permission denied" on an exec, it automatically requests approval from you via this dashboard.

Telegram msg → EACCES → Tool call → Dashboard → Approved → Retry succeeds

Test Prompts for Telegram

Telegram Message Expected
Run: curl https://httpbin.org/ip Blocked → permission request → approve here
Run: python3 -c "print('hi')" Blocked → permission request → approve here
Read ~/.ssh/id_rsa Auto-denied (in never-approve list)
Write hello to /tmp/test.txt Auto-approved (in auto-approve list)

Landlock limits on-demand file grants

Cgroup agents (like OpenClaw) have an immutable Landlock sandbox applied at launch via restrict_self(). File access grants approved via this dashboard or guardian-ctl only update eBPF maps — Landlock will still block paths not in the original allow list. The daemon returns a warning in the IPC response and guardian-ctl prints it to stderr.

Exec grants work for binaries in standard system paths (/usr/bin, /usr/sbin, etc.) or the agent's exec_allow config, because those have Landlock read access. Binaries at non-standard paths not readable by Landlock will still fail. To permanently allow a new path, add it to the agent's config and restart.

The warning .openclaw/AGENTS.md: Permission denied is expected and harmless.
