Permission Requests

Landlock limits on-demand grants for cgroup agents

Cgroup agents (Tier 1) with default: deny have an immutable Landlock sandbox applied at launch. File access grants approved here only update the eBPF layer — Landlock will still block paths not in the original allow list. Exec grants work for binaries in standard system paths (/usr/bin, /usr/sbin, etc.) or the agent's exec_allow config, because those paths have Landlock read access. Binaries at non-standard paths not readable by Landlock will still fail even with an exec grant. To permanently allow a new path, add it to the agent's policy and restart the agent.
